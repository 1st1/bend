# Developer tools

Web inspection and opt-in native input diagnostics.

See [[lat.md/tests/developer-tools-tests|Test coverage]].

## Developer tools

The Develop menu opens WebKit's inspector or JavaScript console for the focused visible web pane, exposing native console errors, script evaluation, network requests, DOM inspection, and debugging.

[BrowseApp.swift](../../Sources/Browse/BrowseApp.swift) routes Show/Close Web Inspector (Command-Shift-I) and Show JavaScript Console (Option-Command-C) to the active browser window's focused page. Commands are disabled for native Bend pages and while unrelated utility windows have focus. Page WebViews retain public inspection support, including Safari's Develop menu, across replacement.

[BendInspectorSupport.m](../../Sources/WebKitFindSupport/BendInspectorSupport.m) isolates optional WebKit inspector and developer-extras SPI behind selector checks. The adapter connects without opening WebKit's separate window and hands its native frontend to [DeveloperToolsPanel.swift](../../Sources/Browse/DeveloperToolsPanel.swift). The inspector's own toolbar provides close, bottom docking, and right docking; a frontend-only message bridge routes those controls to [WebSurfaceHost.swift](../../Sources/Browse/WebSurfaceHost.swift). Left docking and detaching are hidden, and WebKit's native window-drag and resize handlers are disabled. The toolbar uses an opaque, flat dark background without blur, gradients, or glass effects. No extra title row is added, and inspector chrome cannot move the browser window.

The inspector stays inside its source pane below the title/find header, with an AppKit divider that adjusts height when bottom-docked or width when right-docked. Each mounted host retains its dock position and separate sizes across closure; switching positions retains the live inspector and console. If an element-inspection or debugger reveal reparents the frontend, the panel detects removal and restores embedding after WebKit finishes. The adapter hides WebKit’s native presentation without closing its backend, then remounts the same frontend and reapplies the pane layout; native auto-resizing no longer competes with Bend. The page viewport shrinks accordingly, including in narrow panes below WebKit's native docking minimum width. If direct opening is unavailable, Bend explains how to inspect through Safari. Website documents receive neither the inspector control bridge nor console overrides, and Bend does not persist console logs.

[BrowserStore.swift](../../Sources/Browse/BrowserStore.swift) closes owned inspectors when a pane or browser window closes, a WebView is replaced, or navigation switches to a native Bend page. Ordinary navigation and tab switching retain the page's native inspector connection. Moving a live WebView to a different host closes its old inspector panel. [[lat.md/tests/developer-tools-tests#Developer tools]] verifies real console messages, error/rejection reporting, pane routing, and closure.

## Native input diagnostics

[InputDiagnostics.swift](../../Sources/Browse/InputDiagnostics.swift) provides opt-in, bounded native mouse tracing to distinguish window routing failures from events delivered to WebKit.

Settings’ Development tab controls input and pane logging, disabled by default. The preference persists in app defaults and applies immediately to both streams. Startup reads it before session restoration; disabling drains pending writes and stops recording while preserving existing files. Extension diagnostics remain separate.

Two JSONL streams share a run ID, monotonic sequence, timestamps, native view identities, and stable session pane UUIDs:

- `events.jsonl` records each left-button press, drag, and release at application monitoring, window dispatch, AppKit forwarding, web-view entry/return, pane handles, tab drag monitors, and sidebar resizing. The press pane remains the gesture owner through release even after hiding or reparenting; `receiverPaneID` separately identifies the receiving view or current hit target. Non-pane events have a null pane ID and explicit scope.
- `panes.jsonl` records model membership and transfers, pane and tab drag lifetimes/drop targets, hover selection, native attachment/detachment, frame changes, hiding/showing, retained tab root updates, zoom/focus, dividers, and programmatic canvas scrolling. It also records address panels, navigation decisions, command-click handling, web-view replacement/configuration, process exits, JavaScript dialogs, and extension activation, popovers, permission prompts, and focus requests. Tab IDs and related pane IDs identify relationships without conflating tabs with panes. Tab hover selection and canvas merge targets use the same lifecycle stream.

Pane UUIDs are assigned to web views before navigation and preserved across replacement. Native snapshots include window activation, drag ownership, first responder, hit-view ancestry, visibility, gesture-recognizer states, and extension-controller/user-script presence. Instrumentation does not consume or redispatch events; it observes our routing boundaries, not WebKit's internal DOM dispatch.

Both streams live in `~/Library/Application Support/BrowsePrototype/InputDiagnostics/`. Each independently rotates at 500 KiB, retaining a `.previous.jsonl` segment of the same maximum size (four files, at most about 2 MiB total). Oversized segments from older builds are discarded when that stream next writes. Separate serial background queues are capped at 64 pending records each; saturation rejects records without blocking input and reports its count in the next accepted record. Clean termination drains queued writes. Native snapshot identities use process-local hashes without retaining objects or registering weak references, so ancestor inspection remains safe during hosting-view destruction. Native addresses can be reused after destruction; pane UUIDs remain the durable identity. The gesture-owner map uses weak window keys only during live input dispatch. Records exclude coordinates, keyboard input, URLs, titles, and page content.

The hooks span [BrowseApp.swift](../../Sources/Browse/BrowseApp.swift), [BrowseWindow.swift](../../Sources/Browse/BrowseWindow.swift), [BrowserStore.swift](../../Sources/Browse/BrowserStore.swift), [BrowserView.swift](../../Sources/Browse/BrowserView.swift), [MountedTabContent.swift](../../Sources/Browse/MountedTabContent.swift), [PaneDragging.swift](../../Sources/Browse/PaneDragging.swift), [TabReordering.swift](../../Sources/Browse/TabReordering.swift), [SidebarResizing.swift](../../Sources/Browse/SidebarResizing.swift), [AddressPanelController.swift](../../Sources/Browse/AddressPanelController.swift), and the extension bridge.
